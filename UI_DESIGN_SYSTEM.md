# NexusPay Design System

## Design Philosophy

NexusPay should feel like:

- Premium
- Intelligent
- Professional
- Trustworthy
- Executive

The application should resemble a financial intelligence platform rather than a simple banking application.

---

## Visual Identity

Dark backgrounds create focus.

White cards present information clearly.

Teal accents represent intelligence and orchestration.

Gold accents represent premium value and branding.

## Cards

Cards should:

- Use rounded corners
- Use subtle elevation
- Use white backgrounds
- Maintain generous spacing

Cards are the primary information container.

---

## Screen Structure

Standard screen layout:

Header

Screen Title

Screen Description

Nexus AI Card

Primary Intelligence Cards

Operational Cards

Action Buttons

---

## Nexus AI Controls

All major screens should display a Nexus AI control card near the top.

The card should:

- Show current AI status
- Allow enable/disable
- Respect master AI settings
- Match Nexus AI screen styling

---

## Dashboard Design

Dashboards should prioritize:

1. Intelligence
2. Status
3. Actions

Users should understand system status within seconds.

---

## Responsive Design

Support:

- Phones
- Foldables
- Tablets

Large screens:
- Horizontal layouts

Small screens:
- Stacked layouts

Never allow text overlap.

Never allow clipping.

---

## Typography

Hierarchy is important.

Titles:
- Large
- Bold

Section Headers:
- Strong
- Clear

Descriptions:
- Concise
- Readable

Operational data:
- Highly visible

---

## User Experience Rules

Consistency is more important than novelty.

Do not introduce new patterns when existing patterns already exist.

Users should instantly recognise controls across screens.

Every screen should feel like part of the same platform.
