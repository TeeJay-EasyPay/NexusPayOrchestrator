# Corporate Workspace V2 Roadmap

Date: 2026-06-06

## Constraint Applied
No corporate functionality modified in this sprint.

## Review Focus Areas
- Treasury Command Centre
- Corridor Management
- Route Intelligence
- Executive Intelligence
- Partner Management
- Compliance Monitoring
- Liquidity Management
- Operational Visibility

## Current Observation
Corporate workspace architecture remains functionally rich and operation-oriented, but can benefit from progressive refinement and modularization for scale.

## Recommendation Roadmap
1. Treasury Command Centre
- Introduce corridor liquidity stress index trends and threshold alerts.
- Add replayable liquidity decision timeline for auditability.

2. Corridor Management
- Add certification-state heatmap by corridor with latest evidence links.
- Add sentinel corridor escalation ribbon with action owner labels.

3. Route Intelligence
- Add provider drift delta panel (score changes over time).
- Add confidence explainability snapshots for each recommended route.

4. Executive Intelligence
- Add board-ready summary export view with risk posture deltas.
- Add decision-impact tracker linked to decision register IDs.

5. Partner Management
- Add partner SLA breach trend and reconciliation queue visibility.
- Add partner failover rehearsal scorecard.

6. Compliance Monitoring
- Add pre-release compliance checklist runtime dashboard.
- Add variance detector for policy exceptions by corridor/provider.

7. Liquidity Management
- Add projected liquidity runway by corridor/rail.
- Add what-if simulation controls for partner outages.

8. Operational Visibility
- Add consolidated event timeline across transfer lifecycle and ops events.
- Add incident drill-down for transfer groups by status cluster.

## Suggested Delivery Sequence
- Phase A: Executive/Compliance visibility upgrades
- Phase B: Treasury/Corridor predictive tooling
- Phase C: Partner and failover performance suite
- Phase D: Unified operational replay and incident analytics

## Governance Recommendation
Run roadmap delivery as additive workstreams under existing Startup V2 and execution-governance gates.
