# Workstream Charters

## Date
2026-06-02

## WS1 Charter: Device Provenance And Authentication Resolution
Authority: release gate only.

Scope:
- Prove commit, build, runtime version, channel, update ID and auth behavior.
- Produce evidence reports and physical-device proof prompt.

Out of scope:
- Product feature remediation.
- Startup V2 redesign.

## WS2 Charter: Consumer Application Build
Authority: implementation preview.

Scope:
- Build Consumer Home, Send, Track, Transfers, Profile, Settings, and Nexus AI.
- Use blue/white card design and consumer-friendly language.
- Avoid operations, treasury, corridor, and enterprise terminology.

Out of scope:
- Treasury logic.
- Payment execution engine.
- Startup/auth architecture.
- Multi-account backend migration.

## WS3 Charter: Multi-Account And User Segmentation Architecture
Authority: architecture only.

Scope:
- Define Demo, Personal, and Enterprise segmentation.
- Define auth model, account switching, ownership, RLS, profile, recipient, transfer, and AI settings ownership.

Out of scope:
- Production database migration.
- RLS policy implementation.
- Consumer app code changes.
