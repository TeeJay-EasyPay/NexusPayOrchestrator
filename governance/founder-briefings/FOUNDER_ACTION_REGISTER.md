# Founder Action Register

## Purpose

This register is the permanent founder action memory for NexusPay governance activities.

Actions must not be deleted automatically.

Historical entries are retained for traceability, auditability, and decision continuity.

## Action Record Template

Each founder action must include:

- Action ID
- Date Raised
- Description
- Recommendation
- Priority
- Status
- Date Closed
- Related Decision
- Related Sprint

## Governance Maintenance Rules

1. New actions are appended with the next sequential Action ID.
2. Actions are never deleted automatically.
3. Closed actions are moved to the closed section with Date Closed populated.
4. Related Decision and Related Sprint fields are mandatory for all records.
